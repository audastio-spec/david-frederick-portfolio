# David Frederick portfolio

This is a static GitHub Pages export of David Frederick's existing Modern Dark portfolio. It preserves the original Ouvri and Roots of Glory graphics and content from the ChatGPT Sites project, with path adjustments for the GitHub Pages project URL. The case studies do not link to private application source repositories.

## Build

```sh
npm ci
npm run build
```

The generated site is in `out/`. GitHub Actions publishes that directory to GitHub Pages after pushes to `main`.
